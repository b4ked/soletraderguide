The 111,000 unregistered LITRG figure (reported 1 October) represents only those already identified; as HMRC processes batches, more recipients will search for what the letter means.

**What the HMRC letter recipients need next — which no STG post addresses:**
1. Confirm they are actually in scope (qualifying income calculation — SE + property only; PAYE/dividends excluded)
2. Choose compatible software (HMRC registration does not select software)
3. Understand that auto-enrolment ≠ compliance (records still must be kept digitally; quarterly updates must still be submitted)
4. Know that soft-landing applies — no penalty points for missed quarterly updates in 2026/27
